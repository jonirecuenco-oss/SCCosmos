# Proyecto Windows + Android

## Contexto
- Aplicación de escritorio C# para Windows.
- Aplicación Android desarrollada con .NET MAUI.
- Ambas aplicaciones están terminadas y funcionando.
- Objetivo: optimizar calidad, rendimiento y mantenimiento.

## Reglas obligatorias
- No cambiar funcionalidades existentes.
- No modificar protocolos de comunicación sin autorización.
- No introducir nuevas dependencias innecesarias.
- No actualizar .NET, MAUI ni NuGet sin autorización.
- No reescribir módulos completos salvo necesidad justificada.
- Preservar formatos de datos y compatibilidad.
- No modificar archivos generados, bin/ ni obj/.

## Método de trabajo
1. Analizar antes de modificar.
2. Explicar el problema y su impacto.
3. Priorizar cambios de bajo riesgo.
4. Limitar cada intervención a un módulo.
5. Mostrar los cambios realizados.
6. Compilar y ejecutar pruebas relevantes.
7. Solicitar autorización antes de grandes cambios.

## Uso eficiente
- Leer únicamente los archivos necesarios.
- Evitar análisis completos repetidos.
- Resumir los hallazgos de forma concisa.
- No ejecutar procesos costosos innecesariamente.
